## [1.0.0](https://github.com/skynight137/aurora-eq/releases/tag/v1.0.0) (2026-08-19)

### Features

* **audio:** add configurable preamp, filters, shelves, EQ, dynamics, output gain, spatial processing, and volume controls
* **eq:** add reset all processing action
* **presets:** add local full-chain preset save, import, export, and sharing
* **service:** keep the processing chain active through a foreground service
* **settings:** show engine attachment and device capability status

### Bug Fixes

* **navigation:** make the bottom-sheet menu scrollable
* **service:** retry audio-engine attachment when Resume processing is pressed
* **settings:** make the settings screen scrollable
