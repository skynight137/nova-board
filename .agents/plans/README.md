# Agent plan checklist convention

Use these symbols consistently in plan checkpoints and acceptance criteria:

- `[✓]` complete and verified
- `[~]` partially complete or intentionally deferred
- `[ ]` not complete

Do not mark a checkpoint `[✓]` until every gate listed in that checkpoint has
passed. A deferred Android-only or provider-dependent check remains `[~]` until
the required test boundary exists.
